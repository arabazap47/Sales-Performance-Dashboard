# Sales Performance Dashboard
📌 Project Overview
This repository hosts an interactive "Sales Performance Dashboard" created using "Power BI" to track, analyze, and unlock critical insights from online sales data. By transforming raw transactional entries into dynamic visuals, this project simplifies complex metric tracking and supports data-driven business planning.

🛠️ Key Technical Learnings & Application
During the end-to-end development of this analytics tool, the following implementation strategies were achieved:

* Data Engineering & Modeling: Formed robust relational connections and tables joins across disparate datasets to construct an optimized analytical framework.
* Complex Data Manipulation: Authored technical DAX calculations and data clean-up procedures to structuralize raw indicators into cohesive operational metrics.
* User-Driven Navigation: Configured advanced parameter configurations enabling multi-layer drill-downs within worksheets for granular item inspection.
* Customized Interactivity: Built comprehensive slicing filters and global dashboard slicers allowing end-users to effortlessly scope timelines, categories, or regions.

---

## 📈 Specialized Visualizations Implemented
Rather than relying on default presets, the reporting view integrates customized graphics for advanced storytelling:
* Distribution Charts: High-impact Bar, Clustered Bar, Pie, and Donut charts mapping volumetric contribution.
* Trend & Vector Analysis: Precise Line and Area charts detailing performance trajectories over time.
* Correlation & Geo-Mapping: Scatter charts highlighting anomaly variables paired with interactive Maps for regional shipment monitoring.

## 🚀 How to Open the Dashboard Locally
1. Clone the repository to your workstation:
   ```bash
   git clone https://github.com
   ```
2. Launch [Power BI Desktop](https://microsoft.com) on your machine.
3. Open the file **`Ecommerce Sales Dashboard.pbix`**.
4. Note: If a file path warning surfaces, navigate to `Transform Data > Data Source Settings` to refresh the reference paths pointing to your local target `Orders.csv` and `Details.csv` sheets.
